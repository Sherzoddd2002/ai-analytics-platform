# AI Analytics Platform

Julius.ai uslubidagi professional AI analitik platforma.

## Imkoniyatlar

- **Fayl Yuklash**: CSV, Excel (.xlsx, .xls), JSON, TSV
- **Avtomatik Dashboard**: Statistik kartalar va avto-grafiklar
- **Ma'lumot Tozalash**: Dublikatlar, yetishmayotgan qiymatlar, anomal qiymatlar, normalizatsiya, kategoriyali kodlash
- **Grafiklar**: Scatter, Line, Bar, Histogram, Box, Violin, Pie, Area, Heatmap, 3D Scatter, Sunburst, Treemap
- **Machine Learning**: Regression (Linear, Random Forest, Gradient Boosting, Decision Tree), Classification, Auto-model selection
- **Klasterlash**: K-Means, Elbow Method, PCA vizualizatsiya
- **Statistik Tahlil**: Korrelyatsiya, T-Test, Taqsimot (Shapiro-Wilk, Skewness, Kurtosis)
- **AI Insights**: Avtomatik ma'lumot tahlili va tavsiyalar
- **Yuklab Olish**: Tozalangan ma'lumotni CSV/Excel/JSON formatda

## O'rnatish

```bash
pip install -r requirements.txt
```

## Ishga tushirish

```bash
python app.py
```

Brauzerda oching: http://localhost:5000

## Texnologiyalar

- **Backend**: Flask, Pandas, NumPy, SciPy, Scikit-learn, Statsmodels
- **Frontend**: HTML5, CSS3, JavaScript, Plotly.js
- **Vizualizatsiya**: Plotly

## Foydalanish

1. Fayl yuklang (CSV/Excel)
2. Dashboard'da avtomatik grafiklarni ko'ring
3. Tozalash bo'limida ma'lumotni tozalang
4. Grafiklar bo'limida maxsus grafiklar yarating
5. ML bo'limida bashorat qiling yoki klasterlang
6. AI Insights'da avtomatik tavsiyalarni o'qing
